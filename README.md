# 🎨 マンホールカード まっぷ！ (Manhole Card Map App)

下水道広報プラットホーム（GK-P）から全国のマンホールカード情報を自動収集し、OpenStreetMap上にプロット・検索できるWebアプリケーションです。  
子どもから大人まで楽しめる、明るくポップで親しみやすいデザインで作成されています。

---

## 🌟 主な機能・特徴

1. **全国全カード（1,300枚以上）を網羅**
   - 下水道広報プラットホーム（GK-P）の最新マンホールカード情報をスクレイピングで自動取得。
   - 国土地理院ジオコーディングAPIにより、すべてのカード（100.0%）の正確な緯度経度を自動取得・プロット。

2. **ポップ＆親しみやすい子ども向けデザイン**
   - Google Fonts **「Zen 丸ゴシック」** を採用。
   - 明るく温かみのあるパステルカラー（スカイブルー、サンセットオレンジ、イエロー）。
   - 本物のマンホール蓋デザイン（鉄蓋外輪・同心円同心格子・中央ハブ）を描いた特製**マンホール型SVGピンマーカー**。

3. **スマートフォン（iPhone / Android）完全最適化**
   - 地図が画面**100%全画面（`100dvh`）**で広々と表示。
   - Google Maps / Apple Maps スタイルの**フローティング検索バー＆ピルボタン**。
   - 「🎛 絞り込み」ボタンをタップすると、スムーズに立ち上がるボトムシート形式の条件設定ドロワー。

4. **市町村名検索＆リアルタイムマップ移動**
   - 検索ボックスに「札幌市」「戸田市」「豊中市」などを入力すると候補を表示し、選択した地域へアニメーション移動してカード詳細を開きます。

5. **便利なフィルター＆アクション**
   - **47都道府県フィルター**: 日本の標準47都道府県を北から南の順で選択可能。
   - **弾数フィルター**: 第01弾〜最新弾まで絞り込み。
   - **📍 現在地付近を探す**: 位置情報APIで今いる場所の近くのカードを発見。
   - **🎲 おまかせ表示**: ランダムに全国のカードを1枚ピックアップして旅気分を体験。

6. **カード詳細モーダル＆高画質画像拡大**
   - 配布場所の名称、住所、電話番号、配布時間、公式在庫状況リンクを完備。
   - 「🧭 Googleマップでルート案内」ボタンで目的地へ直行。
   - カード画像をタップすると大画面ライトボックスでカードデザインを拡大鑑賞。

## 🚀 使い方・起動手順

### 1. Webアプリの起動（閲覧）

Pythonの標準HTTPサーバーを使用して、ローカルWebサーバーを起動します。

```bash
python3 -m http.server 8080
```

起動後、Webブラウザ（PCまたはスマートフォン）で以下のアドレスを開きます：

👉 **[http://localhost:8080](http://localhost:8080)**

---

### 2. データ更新スクリプトの実行

最新のマンホールカード情報を再取得・更新したい場合は、以下のコマンドを実行します。

```bash
python3 update_csv.py
```

- GK-PのWebサイトから情報をスクレイピングします。
- 国土地理院APIでマルチスレッド並列ジオコーディングを実施し、`manhole_cards.csv` を自動更新します。

## 🛠️ 使用技術 (Tech Stack)

- **フロントエンド**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **地図ライブラリ**: [Leaflet.js](https://leafletjs.com/), [Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster)
- **タイルマップ**: [OpenStreetMap](https://www.openstreetmap.org/)
- **CSVパース**: [PapaParse](https://www.papaparse.com/)
- **タイポグラフィ・アイコン**: Google Fonts (Zen Maru Gothic), FontAwesome 6
- **バックエンド・スクレイピング**: Python 3, BeautifulSoup4, urllib, `concurrent.futures`
- **位置情報API**: 国土地理院 ジオコーディング API (`msearch.gsi.go.jp`)
